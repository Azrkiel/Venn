# Lighter copy and tactile interactions

Goal: make Venn feel clear and responsive with fewer explanations and brief, visible feedback for actions.

Architecture: preserve the scheduling/auth/calendar behavior; simplify copy in the existing creation, signup and response screens. Apply shared press feedback through a small client component and scoped interaction CSS. Calendar cells use colour feedback only, keeping hit targets stable while dragging.

Tech stack: existing React/Next.js, CSS modules, native Web Animations API, Playwright and Vitest. No animation dependency.

```text
Tap / keyboard click -> control compresses -> brief rebound -> stable
Select calendar slot -> immediate colour change (no geometry movement)
Save -> Saving (busy/disabled) -> Saved/check (confirmed response only)
Copy -> Copied/check (clipboard success only)
Error -> concise visible message, edits preserved
Reduced motion -> instant states and focus cues, no animated movement
```

- `src/components/interaction-feedback.tsx`, `src/app/interactions.css`, `src/app/layout.tsx`: lightweight delegated control feedback, CSS press/hover/focus states and reduced-motion support. Exclude draggable availability cells and disabled controls from scale animations.

Keep accessible labels, calendar privacy and unknown-state handling intact.
- `src/app/venn/{create-venn.tsx,venn.module.css,page.tsx}`, `src/app/signup/page.tsx`: concise creation/signup copy, stronger selected planning-span cards, clear clipboard success and subtle result reveal.
- `tests/e2e/ui-polish.spec.ts` plus existing browser expectations: verify visible save pending/success, control acknowledgement, reduced motion, preserved drag geometry, concise first-screen guidance and unchanged functional journeys. Prefer behaviour checks over tests that restate CSS.
